# Сайт резюме команды

[Открыть опубликованный сайт](https://frontend-projectaiu.github.io/Daily-toolkit/site2_resume/team-site/)

Статический сайт с резюме участников и заданиями в отдельных вкладках внутри `index.html`. Откройте `index.html` в браузере, чтобы посмотреть сайт.

## Последние изменения

- 25 сентября 2026: обновлены оформление главной страницы и страницы профиля, а также работа карточек участников.
- 25 сентября 2026: добавлен раздел с заданиями по DOM: изменение, добавление и удаление элементов, переключение класса `active` и вывод списка классов.
- 9 октября 2026: добавлены задания 3 и 4 — интерактивная таблица и переключатель тёмной темы.
- 9 октября 2026: CRUD-практика на DummyJSON находится во вкладке «Задание 5 CRUD/API» на `index.html`; товары показаны карточками, форма добавления и изменения раскрывается над списком.
- 16 октября 2026: добавлены три вкладки с пользователями DummyJSON: GET по ID и карточка с подробным модальным окном, фильтр по имени/нику и полу, сортировка по имени/нику/возрасту/ID.

Данные участников находятся в `data.js`, логика сайта — в `script.js`, а задания по DOM — в `dom-task.js`.
Задания 6–8 используют `users-lab.js` и `users-lab.css`. Список пользователей загружается из `GET /users?limit=0`, а поиск по ID и подробности — из `GET /users/{id}`.
DummyJSON только имитирует запись, изменение и удаление: результаты CRUD видны до перезагрузки страницы.
